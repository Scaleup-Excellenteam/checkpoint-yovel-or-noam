איך הטכנולוגיות בפרויקט עובדות?

הפרויקט הוא צ׳אט מאובטח בסיסי: הלקוח קולט את המשתמש, והשרת מחליט מי נכנס ואיזו הודעה מותר להפיץ.

הרשמה ב־REST ← קבלת Token ← חיבור WebSocket ← בדיקות אבטחה ← שמירה והפצה לחדר

Python ומבנה לקוח–שרת

מה זה? Python היא שפת התכנות. הלקוח מתקשר עם שרת מרכזי שמנהל את המערכת.

איך ביצענו? cli_client.py קורא קלט; server.py מאמת, בודק ומפיץ.

למה בחרנו? Python קריאה ונוחה לרשת. שרת מרכזי מונע הסתמכות על בדיקות בצד המשתמש.

REST, WebSocket ו־JSON

מה זה? REST הוא בקשה ותשובה. WebSocket הוא חיבור פתוח בזמן אמת. JSON הוא מבנה הנתונים שנשלח ביניהם.

איך ביצענו? הרשמה וכניסה עוברות ב־HTTP בפורט 8000; הצ׳אט עובד ב־WebSocket בפורט 8765.

למה בחרנו? REST מתאים לפעולה קצרה; WebSocket מאפשר לקבל הודעות מיד; JSON פשוט לקריאה.

SQLite

מה זה? מסד נתונים ששומר מידע בתוך קובץ מקומי.

איך ביצענו? טבלת משתמשים שומרת גיבובי סיסמאות וטבלת הודעות שומרת רק הודעות שאושרו.

למה בחרנו? הוא מובנה ב־Python, פשוט לדמו ואינו דורש שרת מסד נתונים נוסף.

סיסמאות ו־Token

מה זה? גיבוב הופך סיסמה לערך שלא אמורים להפוך בחזרה. Token הוא כרטיס כניסה זמני.

איך ביצענו? הסיסמה עוברת PBKDF2-HMAC-SHA256 עם מלח אקראי. לאחר כניסה נוצר Token אקראי לשעה ונשמר בזיכרון השרת.

למה בחרנו? הסיסמה אינה נשמרת בגלוי ואינה נשלחת שוב בכניסה לצ׳אט. ה־Token שלנו פשוט ואינו JWT.

DLP

מה זה? מנגנון שמונע דליפה של תוכן שהוגדר כרגיש.

איך ביצענו? dlp.py מחפש אננס, סימני סוד ומבנה של מתכון. הבדיקה מתרחשת לפני שמירה והפצה.

למה בחרנו? כללי טקסט קבועים מהירים, צפויים וקלים להסבר בדמו.

Anti-Bot ו־VirusTotal

מה זה? VirusTotal אוסף מידע על המוניטין של כתובות IP ציבוריות.

איך ביצענו? reputation.py שולח IP ציבורי ל־API וחוסם תוצאה זדונית או חשודה. תוצאות נשמרות זמנית במטמון.

למה בחרנו? מקבלים מידע אבטחה ממקור חיצוני בלי לבנות מאגר כתובות משלנו.

הגבלת קצב ו־asyncio

מה זה? הגבלת קצב מצמצמת הצפה. asyncio מאפשר לטפל בכמה חיבורי רשת בזמן דומה.

איך ביצענו? השרת סופר פעולות בחלונות זמן ומנתק חריגות. בזמן שחיבור ממתין, await מאפשר לטפל באחרים.

למה בחרנו? כך משתמש אחד לא עוצר את כולם וקשה יותר להציף את השירות.

בדיקות וכלי אבטחה

מה זה? כלים שמוודאים שהקוד עובד ושאין בעיות מוכרות.

איך ביצענו? pytest בודק כניסה, חדרים, DLP ו־WebSocket; ‏Bandit סורק קוד ו־pip-audit סורק ספריות.

למה בחרנו? בדיקה אוטומטית חוזרת נותנת הוכחה שהתנהגות חשובה לא נשברה.

המגבלות החשובות: ה־DLP מבוסס על מילים ולא מבין משמעות; בדיקת IP אינה מוכיחה שהמשתמש אנושי; אין הרשאה מיוחדת לחדר הסודי; ותקשורת הלקוח משתמשת כרגע ב־HTTP וב־WS ללא הצפנה.
