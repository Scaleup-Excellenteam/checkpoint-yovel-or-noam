TSPO - מימוש אבטחה

הסבר על מניעת דליפת מתכונים ועל חסימת כתובות IP חשודות.

1. DLP - הגנה על הודעות

כל הודעה נבדקת בשרת לפני שמירה בבסיס הנתונים ולפני שליחה לחדר הצ'אט.

לקוח שולח הודעה → השרת מפעיל DLP → הודעה מותרת: נשמרת ונשלחת → הודעה אסורה: נחסמת
כללדוגמהתוצאה
אננס אסורpineapple או אננסDLP_FORBIDDEN_PINEAPPLE
סוד TSPOTSPO_SECRET_RECIPEDLP_EXPLICIT_SECRET
הצהרת מתכוןמתכון, מרכיבים, recipeDLP_RECIPE_DECLARATION
מבנה של מתכוןמרכיב יחד עם פעולה כמו לערבב או לאפותDLP_RECIPE_STRUCTURE

הודעה חסומה לא נשמרת, לא נשלחת למשתמשים אחרים, והלוג שומר רק את סיבת החסימה. אחרי שלוש הפרות DLP החיבור נסגר.

2. Anti-Bot - הגנה בכניסה

כאשר לקוח פותח WebSocket, השרת בודק את כתובת ה-IP לפני token, התחברות או בחירת חדר.

חיבור חדש → קריאת IP → בדיקת cache או VirusTotal → החלטת ALLOW או BLOCK → רק לקוח מותר ממשיך לאימות
מצבהחלטהreason code
IP ברשת פרטית בכיתהמותרIP_PRIVATE_NETWORK
VirusTotal מחזיר maliciousחסוםIP_REPUTATION_MALICIOUS
VirusTotal מחזיר suspiciousחסוםIP_REPUTATION_SUSPICIOUS
אין API key או השירות לא זמיןמותר ומתועדREPUTATION_UNAVAILABLE

תוצאת IP נשמרת ב-cache ל-10 דקות. כך לא פונים ל-VirusTotal בכל חיבור חדש. מפתח ה-API נשמר מקומית בקובץ .env, שאינו נכנס לגיטהאב.

3. בדיקות

  • הודעות עם אננס, סודות ומתכונים נחסמות.
  • הודעה חסומה אינה נשמרת ואינה משודרת.
  • שלוש הפרות DLP סוגרות חיבור.
  • IP זדוני נחסם לפני אימות.
  • IP נקי, IP פרטי ושירות מוניטין לא זמין מטופלים בצורה צפויה.

להרצת הבדיקות: python -m pytest -q
